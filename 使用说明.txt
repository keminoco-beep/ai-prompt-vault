【软件简介 / About】
一款完全离线运行、独立界面的本地小工具，用于收集和整理
AI 绘图作品：保存例图、自动提取提示词、标注全部模型、
按大类筛选分类、手动分组管理。支持中 / 英双界面。

【安装与启动 / Install】
· Windows 10 / 11 (64-bit)，免安装，双击 exe 即用
· 首次运行 SmartScreen 提示 → 更多信息 → 仍要运行
· 数据全部保存在 exe 同目录 Library 文件夹（自动创建）

【切换语言 / Switch Language】
左下角「⚙ 设置 / Settings」→ 语言 / Language → 重启生效。

【收藏作品 / Collect】
· 拖入网页例图 / 本地图片，或 Ctrl+V 粘贴
· 粘贴 Civitai 链接（civitai.com / civitai.red）→ 解析并导入，
  自动提取：正负提示词、主模型大类、全部模型清单（可点链接）、
  采样器/步数/CFG/种子/尺寸，并下载原图
· 本地图片自带参数自动填充：A1111 / ComfyUI / NovelAI 导出的
  PNG 拖入或粘贴后，正负提示词、采样参数、模型、LoRA 自动填入
· 「模型清单」可自由增删行（名称/类型/链接）

【图库浏览 / Gallery】
· 平铺大图 / 列表详细信息两种模式（列表点列头排序、拖列宽）
· 排序：时间/标题/主模型/模型/尺寸；筛选：大类/比例/LoRA/来源/搜索
· 悬停图片 → 图片预览悬浮窗；选中 → 右侧详情面板（复制全部/正/负）
· 右键：复制提示词、加入分组、打开模型页、打开所在文件夹、删除
· 双击 → 详情/编辑对话框
· 手动分组：左侧「图片分组」，新建/重命名/删除，计数实时更新

【数据管理 / Data】
所有数据在 exe 同目录 Library/：
  data.json（索引） images/（原图） thumbs/（缩略图）
  trash/（回收站） settings.json（语言设置）
· 复制整个 Library 文件夹即可备份 / 迁移
· 旧版「资料库」文件夹首次启动自动迁移为 Library

【常见问题 / FAQ】
· Civitai 导入偶尔失败：网络波动，自动重试，稍后再试
· 网页拖图失败：防盗链 → 保存本地后拖入文件
· 换电脑：拷贝 Library 文件夹即可
