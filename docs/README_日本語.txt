      AI Prompt Vault  v3.1.0
      AI イラスト資料を整理（参考画像 + プロンプト + モデル）
      対応言語：中文 / English / Español / 日本語
══════════════════════════════════════════════════════════

【ソフトウェア紹介】
完全オフラインで動作する、独立した画面を持つローカル用の
小さなツールです。AI イラスト作品の収集・整理に特化して
います。参考画像の保存、プロンプトの自動抽出、全モデルの
記録、ベースモデルによる絞り込み、手動グループ管理に加え、
ComfyUI の生成画像をギャラリーで直接閲覧できます。v3.1.0
からは 中文 / English / Español / 日本語 の 4 言語表示に対応
し、いつでも切り替えられます。

──────────────────────────────────────────────
1. システム要件とインストール
──────────────────────────────────────────────
・Windows 10 / Windows 11（64 ビット）
・環境のインストールは不要。ポータブルな単一 .exe で、
  ダブルクリックするだけですぐ使えます
・完全オフライン動作（Civitai リンクのインポートとモデル
  ダウンロードのみインターネット接続が必要）

【初回起動時の SmartScreen 表示について】
コード署名証明書を取得していないため、初回起動時に Windows
が「Windows によって PC が保護されました」と表示する場合が
あります。これは正常です。次の順にクリックしてください：
    詳細情報 → それでも実行
これで通常どおり開きます。（初回のみ。以降はダブルクリック
だけで起動します）

【表示言語の切り替え】
設定 → 表示言語 で 中文 / English / Español / 日本語 を選択
できます。切り替え後はアプリを再起動すると反映され、言語
設定は自動的に保存されます。
（言語設定はライブラリ内に保存され、データと一緒に移行します）

──────────────────────────────────────────────
2. 機能詳細
──────────────────────────────────────────────

【コレクション（画像の取り込み方）】
・画像のドラッグ＆ドロップ：Web 上の参考画像を点線エリアに
  そのままドラッグ（複数枚可）。ローカルの画像ファイルも
  対応
・画像の貼り付け：任意の場所で Ctrl+V、または「画像を
  貼り付け」ボタンをクリック
・ローカル動画：ローカルの動画ファイルをインポート可能
  （先頭フレームのサムネイルを自動生成）
・Civitai リンクのインポート：civitai.com / civitai.red の
  画像・モデル・動画の共有リンクを貼り付けて「解析して
  インポート」を実行すると、以下を自動抽出します：
  - プロンプト（Positive / Negative）
  - ベースモデルの分類（Krea 2 / Flux.1 / Flux.2 / SDXL /
    Pony / Illustrious / NoobAI / SD 1.5 / SD 3.5 など）
  - 使用した全モデル一覧（Checkpoint / LoRA / Embedding /
    VAE など）。各モデルに Civitai ページへのリンク付きで、
    「開く」をクリックすると直接ジャンプ
  - サンプラー、ステップ数、CFG、シード、画像サイズ
  - 元画像の自動ダウンロード。動画リンクの場合は動画ファイル
    をダウンロードし、ギャラリー用に先頭フレームのサムネイル
    を自動生成
  ヒント：複数のリンクを一度に貼り付けられます（スペース
  または改行で区切り）。

【ローカル PNG のパラメータ自動抽出（重要）】
SD WebUI（A1111）、ComfyUI、NovelAI から書き出した PNG には
生成パラメータが埋め込まれています。このような画像を
ドラッグまたは貼り付けると、ソフトが自動的に読み取って
入力します：プロンプト（Positive / Negative）、サンプラー、
ステップ数、CFG、シード、モデル名、LoRA（ステータスバーに
「画像内のプロンプトを自動抽出しました ✓」と表示されます）。

【ComfyUI 出力ギャラリー（マイ作品）】
設定で「ComfyUI出力フォルダ」を 1 つ以上追加できます（複数フォルダ対応。旧バージョンの自動結合 output の
代わりになります）。保存すると即座に反映され、ソフトはこれら
のフォルダ（サブディレクトリ含む）をバックグラウンドで
スキャンし、生成画像を「仮想参照」としてギャラリーに追加
します——ファイルはコピーせず、余分なディスク容量も使いません：
・グループツリーに「マイ作品」グループが出現。出力フォルダが
  複数の場合は「マイ作品 / <フォルダ名> / <サブフォルダ>」と
  自動的に階層化されます
・各作品の生成パラメータ（プロンプト / サンプラー / モデル /
  LoRA など）を自動抽出して表示
・ディスクキャッシュ：初回スキャン結果をキャッシュするので、
  次回以降は起動が秒単位で完了。サムネイルも専用キャッシュ
  あり
・スキャン高速化：マルチスレッド並列解析により、実測で
  4,877 枚が約 4.5 分から約 45 秒に短縮、  約 6.5 倍高速化
・キャッシュディレクトリの不一致を  自動検出して再スキャン
・スキャンのフリーズを修正：古いスキャンスレッドを整理 +
  タイムアウトによる保険
・レンダリング上限でカクつき防止：仮想作品が多い場合は先頭
  N 件のみ表示。大量画像のギャラリーはチャンク単位でレンダ
  リングされるため、ウィンドウは固まらず、画像が順番に
  表示されます
・ギャラリーツールバーの「更新」ボタン：出力フォルダに新しい
  画像が増えたら、クリックするだけでバックグラウンド再スキャン
  を手動実行（リアルタイム監視はせず、リソースを節約）
・「ファイル欠落」マーク：元ファイルが移動・削除された作品は
  ギャラリーで明確にマークされます
・設定保存後はギャラリーが即座に更新され、スキャン中は
  「出力フォルダをバックグラウンドでスキャン中...」と表示
・仮想作品をダブルクリックすると詳細を確認できますが、
  ライブラリにはコピーされません（ディスクの二重使用を回避）

【ギャラリーの閲覧】
・2 つの表示モード：
  - グリッド：大きなサムネイル表示。「サイズ」スライダーを
    ドラッグしてセルの大きさを変更
  - リスト：ファイルマネージャー風の詳細テーブル（サムネイル /
    タイトル / ベースモデル / モデル一覧 / プロンプト / サイズ /
    インポート日時）。列ヘッダーをクリックで並び替え、列の
    区切りをドラッグで幅を調整
・並び順：インポート日時 / タイトル / ベースモデル / モデル /
  サイズ、昇順・降順（リストモードでは列ヘッダークリックも有効）
・絞り込み：ベースモデルの分類、画像比率、使用 LoRA、ソース、
  キーワード検索（モデル名 / ベースモデル分類を検索可能）
・画像にホバー：クリーンな大きめプレビューがポップアップ表示
・画像を選択：右側の固定パネルに完全な詳細（大画像、プロンプト、
  サンプリング設定、モデルリンク、グループ）を表示。すべて /
  Positive / Negative をワンクリックコピー
・画像を右クリック：プロンプトのコピー、グループに追加、
  ベースモデルのページを開く、フォルダを開く、レコード削除
・画像をダブルクリック：詳細 / 編集ダイアログを開き、情報の
  変更、コピー、削除が可能

【手動グループ】
左サイドバー下の「画像グループ」エリア：
・「＋ 新規」をクリックしてカスタムグループを作成（名前変更 /
  削除いつでも可能）
・画像を右クリック →「グループに追加 ▸」でグループを選択、
  または「現在のグループから削除」
・グループ名をクリックすると、そのグループの画像だけを表示
  （件数付き）
・グループデータはライブラリに保存され、PC 移行後も保持

【一括操作 / エクスポート】
複数画像を選択すると、次の一括操作が可能です：
・グループへ一括移動 / 一括削除（ゴミ箱へ移動）
・一括エクスポート：CSV または Markdown。全レコードまたは
  プロンプトのみ
・エクスポート内容：タイトル、プロンプト、モデル一覧、
  パラメータ、ソースリンクなど

【重複検索】
・ワンクリックで視覚的に重複した画像を検出（知覚ハッシュ）。
  プレビューを比較して最も鮮明な 1 枚を残し、残りはゴミ箱へ
・「重複削除後に再起動すると復活する」問題を修正：
  削除結果がインデックスに書き戻されるため、復活しません。

【複数ライブラリ】
・設定 → ライブラリの場所 → 変更 で、新しいライブラリ
  ディレクトリを指定できます。再起動後に反映され、旧ライブラリ
  のデータは影響を受けません
・ライブラリ同士は完全に独立しているため、テーマ別に分けて
  管理するのに最適です

【ライト / ダークテーマ】
・設定 → テーマ で ダーク / ライト を切り替え。即時反映

【A1111 出力ギャラリーのワンクリックインポート】
・設定 → A1111 outputs フォルダ（任意）。設定すると、
  Automatic1111 が生成した画像（プロンプトパラメータ含む）を
  ギャラリーからワンクリックでライブラリにインポート。
  重複画像は自動的にスキップ

【モデルの健全性チェック】
モデル管理ページで ComfyUI のモデルフォルダ（サブディレクトリ
含む）を自動スキャンし、モデルファイルの健全性（破損 / 0 バイト /
.part 残骸）をチェックします。異常のあるモデルは赤い ⚠ マークで
表示され、ツールバーに異常件数が集計されます。
（.txt などの説明ファイルは自動的に無視されます）

【ComfyUI へのモデルダウンロード】
・設定 → ComfyUIルートフォルダ（独立した設定項目。
  モデルダウンロード専用で、出力フォルダとは干渉しません）
・ギャラリー / 詳細パネルで「モデルをダウンロード」をクリック
  すると、画像が使用しているモデルを ComfyUI の対応モデル
  フォルダにワンクリックでダウンロード
・「ダウンロード一覧」ページで進捗確認、一時停止 / 再開、
  履歴表示が可能
・ダウンロードが 403 / HTML エラーページになる場合は、設定で
  Civitai API Key（civitai.red ユーザーセンターで生成）を
  入力して再試行してください

──────────────────────────────────────────────
3. データ管理
──────────────────────────────────────────────
すべてのデータは、exe と同じ場所の Library サブフォルダに
自動保存されます（初回起動時に自動作成。旧版の中国語名
「资料库」フォルダは自動的に移行されます）：

    Library/
    ├── library.db                # SQLite データベース（レコード / グループ / 設定）
    ├── settings.json             # 設定（言語、テーマ、パスなど）
    ├── images/                   # 元画像
    ├── videos/                   # インポートした動画
    ├── thumbs/                   # サムネイル（閲覧高速化）
    ├── comfy_output_cache.json   # 「マイ作品」スキャンキャッシュ
    ├── comfy_output_thumbs/      # 「マイ作品」サムネイル
    └── trash/                    # ゴミ箱（削除したレコードの一時置き場）

・サイドバーの「ライブラリフォルダを開く」ボタンで直接開けます
・Library フォルダごとコピーすれば、バックアップ / 移行完了
・削除したレコードはゴミ箱に移動するだけで、すぐに物理削除
  されません
・複数ライブラリ：設定で新しいライブラリディレクトリを指定
  （再起動後に反映。旧ライブラリのデータはそのまま）
・テーマ：設定で ダーク / ライト を切り替え（即時反映）

──────────────────────────────────────────────
4. よくある質問
──────────────────────────────────────────────
・Civitai のインポートがたまに失敗する：Civitai への接続が
  不安定な場合があります。ソフトは civitai.com と civitai.red
  を自動で切り替えて再試行するので、少し待って再試行して
  ください
・Web からの画像ドラッグが失敗する：ホットリンク防止がある
  場合は、画像を保存してからローカルファイルをドラッグして
  ください
・PC を買い替えた場合：Library フォルダごとコピーして開くだけ
  ですべて引き継がれます
・「マイ作品」が表示されない：設定の「ComfyUI出力フォルダ」が
  正しいか確認してください。初回スキャンはバックグラウンドで
  行われるので少し待つか、ギャラリーツールバーの「更新」ボタン
  で手動スキャンを実行してください
・「マイ作品」が「ファイル欠落」になる：元ファイルが移動または
  削除されたことを意味します。ギャラリーは元のパスを参照して
  いるだけなので、出力フォルダを確認してください
・スキャンに時間がかかる？：マルチスレッド並列解析
  で大幅に高速化（実測 4,877 枚で約 45 秒）。巨大なフォルダの
  初回スキャンは少し時間がかかる場合がありますが、その間も
  画面は操作可能です
・モデルダウンロードが 403 / HTML エラーページになる：設定で
  Civitai API Key（civitai.red ユーザーセンター → API Keys で
  生成）を入力して再試行してください
