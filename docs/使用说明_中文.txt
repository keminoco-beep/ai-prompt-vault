      AI 绘图资料整理（AI Prompt Vault）  v3.2.1
      整理收纳 AI 绘画作品（例图 + 提示词 + 模型）
      支持中文 / English / Español / 日本語 四语界面
══════════════════════════════════════════════════════════

【软件简介】
一款完全离线运行、独立界面的本地小工具，用于收集和整理
AI 绘图作品：保存例图、自动提取提示词、标注全部模型、
按大类筛选分类、手动分组管理，并支持把 ComfyUI 生成的
作品直接纳入图库浏览。支持中文、English、Español、
日本語 四种界面语言，可随时切换。

──────────────────────────────────────────────
★ 核心功能一览 / Features
──────────────────────────────────────────────
· 收藏作品：把网页上的例图直接拖进来、Ctrl+V 粘贴，或
  粘贴 Civitai 图片·模型·视频分享链接一键导入（自动提取
  提示词、模型清单与采样参数，并下载原图 / 视频）
· 图库浏览：平铺 / 列表双模式，支持排序、多条件筛选与
  关键词搜索；列表悬停显示大图预览；导入的视频正确显示
  分辨率
· 我的作品：设置「自动导入文件夹」（如 ComfyUI 输出目录）
  后，新生成的图片自动出现在图库，无需手动刷新；按文件夹
  自动分组；显示数量可在设置中调整
· 模型管理：一键扫描模型目录做健康检查（损坏 / 0 字节 /
  残留文件一目了然），并可直接把图片用到的模型一键下载到
  ComfyUI 对应文件夹
· 分组管理：创建自定义分组，配合「我的作品」自动分组树，
  按主题轻松整理
· 重复检测：一键找出内容重复的图片，对比后保留最清晰的一张
· 批量导出：多选图片批量导出为 CSV / Markdown（可仅导出
  提示词）
· 多资料库：可切换 / 新建资料库目录，不同主题分开存放
· 亮 / 暗主题：一键切换，即时生效
· 四语界面：中文 / English / Español / 日本語，随时切换

──────────────────────────────────────────────
一、系统要求与安装
──────────────────────────────────────────────
· Windows 10 / Windows 11（64 位）
· 无需安装任何环境，绿色单文件，双击即用
· 完全离线运行（仅 Civitai 链接导入、模型下载时需要联网）

【首次运行提示（SmartScreen）】
因软件未购买代码签名证书，Windows 首次运行可能提示
"Windows 已保护你的电脑"。这是正常现象，请点击：
    更多信息 → 仍要运行
即可正常打开。（仅第一次需要，之后直接双击即可）

【界面语言切换】
设置 → 界面语言，可选 中文 / English / Español / 日本語。
切换后重启软件生效，语言偏好自动保存。
（语言设置保存在资料库中，随数据一起迁移）

──────────────────────────────────────────────
二、功能详解
──────────────────────────────────────────────

【收藏作品（如何把图片收进来）】
· 拖入图片：把网页上的例图直接拖进虚线区域（支持多张），
  也可以拖入本地图片文件
· 粘贴图片：任意位置按 Ctrl+V，或点「粘贴图片」按钮
· 本地视频：支持导入本地视频文件（自动提取首帧缩略图）
· Civitai 链接导入：粘贴 civitai.com 或 civitai.red 的
  图片 / 模型 / 视频分享链接 → 「解析并导入」，自动提取：
  - 正向 / 负向提示词
  - 主模型大类（Krea 2 / Flux.1 / Flux.2 / SDXL / Pony /
    Illustrious / NoobAI / SD 1.5 / SD 3.5 等）
  - 全部模型清单（大模型 / LoRA / 嵌入 / VAE 等），
    每个模型带 Civitai 页面超链接，点「打开」直接跳转
  - 采样器、步数、CFG、种子、图片尺寸
  - 自动下载原图；视频链接则下载视频文件，并自动生成
    首帧缩略图用于图库预览
  提示：支持一次粘贴多个链接（用空格或换行分隔）。

【本地图片自动提取参数（重要）】
从 SD WebUI（A1111）、ComfyUI、NovelAI 导出的 PNG 图片
自带生成参数。拖入或粘贴这类图片时，软件会自动读取并
填充：正向/负向提示词、采样器、步数、CFG、种子、
模型名、LoRA（状态栏提示"已自动提取图片内嵌提示词"）。

【我的作品（自动导入图库）】
设置页可添加一个或多个「自动导入文件夹」（支持多选，如
ComfyUI 输出目录，含所有子目录）。保存后立即生效，软件
在后台扫描这些文件夹，把生成的图片以"虚拟引用"方式加入
图库——不复制文件、不占额外硬盘空间：
· 左侧分组树出现「我的作品」分组；多个文件夹时按
  「我的作品 / <目录名> / <子目录>」自动分层分组
· 每张作品自动提取生成参数（提示词 / 采样器 / 模型 /
  LoRA 等）并显示
· 实时更新：文件夹里的图片新增 / 删除 / 移动后，图库
  自动同步，无需手动刷新；也可以随时点工具栏「刷新」
  按钮立即检查
· 显示数量可调：设置中可限制「我的作品」显示数量
  （默认 250，可调 50~10000）或取消限制
· 图库「文件缺失」标记：源文件被移动 / 删除的作品会打上
  标记，一目了然
· 双击虚拟作品可查看详情，但不会复制进资料库（避免
  双倍占用硬盘）

【图库浏览】
· 两种显示方式：
  - 平铺：大图网格，拖动「大小」滑块缩放图块
  - 列表：类似文件管理器的详细信息表格
    （缩略图/标题/主模型/模型清单/提示词/尺寸/导入时间），
    点列头可排序，拖动列分隔线可调节每栏宽度
· 排序：按导入时间 / 标题 / 主模型 / 模型 / 尺寸，
  升序或降序（列表模式点列头同样生效）
· 筛选：主模型大类、图片比例、使用的 LoRA、来源、
  关键词搜索（支持搜模型名 / 主模型大类）
· 鼠标悬停图片：出现图片预览悬浮窗（纯净大图预览）
· 选中图片：右侧固定面板显示完整详情（大图、提示词、
  采样参数、模型链接、分组），一键复制全部/正向/负向
· 右键图片：复制提示词、加入分组、打开主模型页面、
  打开图片所在文件夹、删除记录
· 双击图片：打开详情/编辑对话框，可修改信息、复制、删除

【手动分组】
左侧栏下方「图片分组」区域：
· 点击「＋新建」创建自定义分组（可重命名/删除）
· 右键图片 → 「加入分组 ▸」选择分组，或「从分组移除」
· 点击分组名即可只看该组图片（带数量统计）
· 分组数据保存在资料库中，换机迁移不丢失

【批量操作 / 导出】
多选图片后可批量：
· 批量改分组 / 批量删除（移入回收站）
· 批量导出：CSV 或 Markdown，可导出整条信息或仅提示词
· 导出内容含：标题、提示词、模型清单、参数、来源链接等

【重复检测（查重）】
· 一键找出内容重复的图片，可对比预览后保留最清晰的一张，
  其余移入回收站

【多资料库】
· 设置 → 资料库位置 → 更换，可指定新的资料库目录；
  更换后重启生效，旧库数据不受影响
· 不同资料库之间互不影响，适合不同主题分类存放

【亮 / 暗主题】
· 设置 → 界面主题，可切换 暗色 / 亮色，即时生效

【模型健康检查】
模型管理页会自动扫描 ComfyUI 模型目录（含各子目录），
检查模型文件健康状况（是否损坏/是否 0 字节/.part 残留），
异常模型以红色 ⚠ 标记，工具栏汇总异常数量。
（自动忽略 .txt 等说明文件）

【模型下载到 ComfyUI】
· 设置 → ComfyUI 根目录（独立设置项，专用于
  模型下载，与自动导入文件夹互不干扰）
· 在图库 / 详情面板点「下载模型」，即可把图片使用的模型
  一键下载到 ComfyUI 对应类别的模型文件夹
· 「下载列表」页可查看下载进度、暂停 / 继续、历史记录
· 若下载遇 403 / HTML 错误页，可在设置中填入 Civitai
  API Key（civitai.red 用户中心生成）后再试

──────────────────────────────────────────────
三、数据管理
──────────────────────────────────────────────
所有数据自动保存在 exe 同目录的 Library 子文件夹中
（首次运行自动创建；旧版中文名「资料库」目录会自动迁移）：

    Library/
    ├── library.db                # SQLite 数据库（记录/分组/设置）
    ├── settings.json             # 设置（界面语言、主题、路径等）
    ├── images/                   # 原图
    ├── videos/                   # 导入的视频
    ├── thumbs/                   # 缩略图（加速浏览）
    ├── comfy_output_cache.json   # 「我的作品」扫描缓存
    ├── comfy_output_thumbs/      # 「我的作品」缩略图
    └── trash/                    # 回收站（删除的记录暂存于此）

· 侧边栏「打开资料库文件夹」按钮可直接打开
· 复制整个 Library 文件夹即可备份 / 迁移全部数据
· 删除记录会移入回收站，不会直接物理删除
· 多资料库：设置中可指定新的资料库位置（换库后重启生效，
  旧库数据不受影响）
· 主题切换：设置中可切换 暗色 / 亮色 主题（即时生效）

──────────────────────────────────────────────
四、常见问题
──────────────────────────────────────────────
· Civitai 导入偶尔失败：国内网络访问不稳定，软件会自动
  在 civitai.com / civitai.red 间切换并重试，稍后再试即可
· 网页拖图失败：图片有防盗链时可右键保存后拖入本地文件
· 换电脑：把 Library 文件夹整个拷走即可，打开即用
· 我的作品不显示：确认设置中的「自动导入文件夹」填写正确，
  首次扫描在后台进行，稍等片刻自动出现；也可以点图库
  工具栏「刷新」按钮立即检查
· 我的作品被标记「文件缺失」：说明源图片文件已被移动或
  删除，图库只是引用了原路径，请检查自动导入文件夹
· 首次扫描大目录要等吗？：扫描在后台进行，期间界面不卡顿；
  首次扫描完成后，之后的新图都会自动同步，无需手动刷新
· 模型下载提示 403 / HTML 错误页：在设置中填入 Civitai
  API Key 后重试（civitai.red 用户中心 → API Keys 生成）
